How to Export from Google Forms

  1. Open your Google Form
  2. Click the Responses tab
  3. Click the Google Sheets icon to open in Sheets
  4. In Sheets: File → Download → Microsoft Excel (.xlsx)
  5. Upload the downloaded file here

How Self-Learning Works

The model improves automatically each time you add data:

🗂️ Upload Batch 1 — e.g. 60 responses from this semester
📈 Model trains on Batch 1 + 3,000 synthetic rows
🗂️ Upload Batch 2 — e.g. 80 more responses next semester
📈 Model retrains on Batch 1 + Batch 2 + synthetic rows
✅ Accuracy improves as the pool grows

Bias Prevention

After every training run the model checks for accuracy gaps across student gender and level subgroups. If any group scores more than 10 percentage points below average, a bias flag is shown above. To fix it: collect more responses from under-represented groups and upload them.
